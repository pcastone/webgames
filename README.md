# Kids Web Games

Three Phaser 3 games for ages 6–8. All art is drawn in code and sounds are synthesized, so there are no asset files.

- **Memory Match**: flip cards to find animal pairs.
- **Balloon Math**: pop the balloon with the right answer (sums to 10, then add/subtract within 20).
- **Word Catcher**: move the basket to catch letters in order to spell the pictured word.

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```
